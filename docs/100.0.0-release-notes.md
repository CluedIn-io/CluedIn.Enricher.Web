### Fixes
- Fixed a RestSharp major-version API break (`Method.GET`/`IRestResponse<T>` on CluedIn 4.7.0/4.8.0 vs `Method.Get`/`RestResponse<T>` on CluedIn 5.0)
- Fixed `NuGet.Config` casing, which broke restore on Linux build agents

### Chore
- Migrated to multi-version CluedIn targeting: CluedIn 4.7.0/4.8.0 (net6.0) and CluedIn 5.0.0-beta.* (net10.0), built as separate packages from a single branch
- Package versioning starts at 100.0.0 - the CluedIn version this package is compiled against is now encoded in the package name suffix instead of tracked by this package's own version. The baseline starts at `100.0.0` (not `1.0.0`) so that customers who saw this repo at `4.x`/`5.x` under the old single-version scheme never see it "go backwards"
- Enabled integration tests in CI, now that `CluedIn.Testing.Base`/`CluedIn.CrawlerIntegrationTesting` are multi-version targeted too
- Fixed a bug where `ExternalSearch.Providers.Web.Provider`'s own dependency on `ExternalSearch.Providers.Web` could pack with an unsuffixed package id (`PackageId` is now derived from `_CluedInPackageSuffix` in `Packages.props` instead of relying on a pipeline-only override)
